# Python - Exception Handling

This project introduces exception handling in Python.

It covers using try and except blocks, handling specific exceptions, and writing functions that can deal with errors safely.

## Task 0: Safe list printing

The `safe_print_list` function prints a specific number of elements from a list.

It uses `try` and `except` to safely handle cases where the requested number of elements is greater than the list size.

## Task 1: Safe integer printing

The `safe_print_integer` function prints an integer safely.

It uses `try` and `except` to handle values that are not integers. It returns `True` when an integer is printed and `False` otherwise.
